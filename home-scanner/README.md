# 우리집 스캐너 (iPhone LiDAR → 3D 플래너)

아이폰 LiDAR와 애플 RoomPlan으로 방을 스캔하고, 결과를 **우리집 3D 플래너**에 넣는 앱이에요.
플래너에서 3D로 보고 Claude에게 인테리어 추천을 받을 수 있어요.

플래너: https://claude.ai/artifact/3WQV259wPgEmK7XhpBjjhR

## 필요한 것

- **LiDAR가 있는 아이폰**: iPhone 12 Pro / 13 Pro / 14 Pro / 15 Pro / 16 Pro / 17 Pro (Max 포함). 또는 LiDAR가 있는 iPad Pro
- iOS 17 이상
- **Mac + Xcode 15 이상** (무료 Apple ID로 설치 가능. 이 경우 7일마다 다시 설치해야 해요)
  - Mac이 없으면 iPad의 Swift Playgrounds 앱으로 열 수도 있어요

## 설치 방법 (Mac)

1. 이 폴더의 `HomeScanner.swiftpm` 을 Mac으로 옮기고 더블클릭해 Xcode로 열어요.
2. Xcode 위쪽에서 실행 대상을 **내 아이폰**으로 고르고, 아이폰을 케이블로 연결해요.
3. 왼쪽에서 HomeScanner를 누르고 **Signing & Capabilities → Team**에서 내 Apple ID를 골라요.
   (처음이면 Xcode → Settings → Accounts에서 Apple ID를 추가)
4. ▶ 실행 버튼을 눌러요.
5. 아이폰에서 처음 실행할 때 "신뢰할 수 없는 개발자"가 나오면
   설정 → 일반 → VPN 및 기기 관리 → 내 Apple ID → 신뢰를 눌러요.
6. 아이폰 설정에서 **개발자 모드**를 켜라고 나오면 켜고 재시동해요.

## 사용 방법

1. 앱에서 방 이름(예: 거실)을 쓰고 **방 스캔 시작**을 눌러요.
2. 천천히 걸으면서 벽 모서리, 문, 창, 가구를 비추고, 다 되면 **스캔 끝내기 → 이 방 저장**을 눌러요.
3. 방마다 반복해요.
4. **도면 데이터 복사**를 누르고 **우리집 3D 플래너 열기**를 눌러요.
5. 플래너 위쪽 **도면 데이터**를 누르고, 붙여 넣은 뒤 **방으로 추가**를 눌러요.
6. 방들은 옆으로 나란히 들어가요. 방을 끌면 안의 가구도 같이 움직이니 실제 배치대로 맞춰 주세요.

## 참고

- 벽은 실제로 스캔한 모양 그대로 들어가요. 가구는 상자 모양으로 단순화돼요.
- RoomPlan이 가구 앞뒤 방향을 반대로 잡는 경우가 있어요. 플래너에서 **90° 회전**을 두 번 누르면 돼요.
- 커튼, 조명, 화분 같은 소품은 RoomPlan이 인식하지 못해요. 플래너에서 직접 추가해 주세요.
