# Subway network snapshot

Source snapshot: 2026-10-21. 799 operator station records on 24 lines.
Coordinates: Seoul TOPIS [역사마스터](https://data.seoul.go.kr/dataList/OA-21232/S/1/datasetView.do), service `subwayStationMaster` (784 records). Station names, operator codes and public numbers: Seoul Metro `SearchSTNBySubwayLineInfo` (799 records). Shared physical station coordinates fill operator aliases where necessary. Attribution: Seoul Metropolitan Government / Seoul Metro, 공공누리 1유형.

Edges follow public station numbers, with explicit handling for Line 1 branches, Line 2 circle and both shuttles, Line 5 Macheon branch, the one-way Eungam loop, Gyeongui Seoul branch, Gyeongchun Gwangundae branch and AREX inserted stations. GTX-A's Seoul–Suseo gap is disconnected. Different through-service patterns have separate routing IDs on shared tracks. The graph is an estimate based on station order, not a timetable or an express-train router. Transfers require matching station names/aliases within 900 m. Bus connections use walking distances up to 300 m.

Climate filtering conservatively includes Seoul sections of the supported lines; the current short-term card excludes out-of-Seoul sections, Shinbundang and GTX. Source: https://news.seoul.go.kr/traffic/archives/510651 (checked 2026-10-21). Airport alighting exception is not generated by this conservative filter.

Live arrivals and positions use the provider's HTTPS API sample transport at `data.seoul.go.kr/dataList/getOpenApiSample.do`, whose UI documents URL encoding and whose responses allow browser CORS. Arrival/position caches last 25 s; only the visible sheet refreshes every 30 s, stopping when hidden/closed. Position markers represent reported stations, not GPS coordinates.

Timetable: https://www.data.go.kr/data/15143847/openapi.do, `/B553766/schedule/getTrainSch`. Parameters follow the embedded official Swagger. Manual lookup only, in-flight deduplication, 24 h persistent station/direction/day cache, 60 s failure cooldown, KST day counter capped at 9,500 attempts per browser. This client-side counter is not an account-wide server quota; other browsers and other applications share the provider's actual 10,000/day allowance. The upstream returned HTTP 400 / INVALID_REQUEST_PARAMETER_ERROR during verification; the UI reports failure and does not invent scheduled departures. On primary failure, the official Seoul `SearchSTNTimeTableByIDService` is used instead, with a one-hour primary cooldown; 367/367 weekday/upbound rows for Sindorim were verified. The displayed source identifies fallback data. Timetables are not used to claim a train is currently operating or to calculate express/last-train routes.
