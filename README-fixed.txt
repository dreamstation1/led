서울 버스 정류소 지도 수정본
수정일: 2026-09-19

적용 내용
- 지도 확대/축소 때 카메라 중심을 유지하고, 지연된 버스 위치 응답이 다른 노선에 섞이지 않게 했습니다.
- 버스 상태에 실제 정류소 이름과 진행 구간을 표시합니다.
- 차량의 lastStnId→nextStId를 노선 정류소 순서와 대조해 정방향/반대 방향을 구분하고, 반대 방향 차량도 그 방향의 실제 구간으로 표시합니다.
- 양방향 정류소가 가까운 구간에서도 GPS 최근접으로 반대편 정류소를 고르지 않고 API의 현재 구간 정류소에 차량 카드를 붙입니다.
- 이동 중 차량 카드는 현재 출발 정류소와 다음 정류소 행 사이를 `sectDist/fullSectDist` 진행률로 움직이며, 정차 차량은 정류소 원 옆에 고정합니다.
- 같은 차량이 같은 구간에 있는 동안에는 직전 진행률을 보존하고 `requestAnimationFrame`으로 계속 보간하므로, 실시간 조회가 갱신될 때 카드가 순간이동하거나 뒤로 튀지 않습니다. 카드에는 `현재 정류소 → 다음 정류소 이동 중`을 표시합니다.
- 제공된 경기도 BMS 정류소/경유정류소 파일과 승인된 경기도 버스노선 API의 노선번호 조회 결과로 3,513개 경기 노선과 14,788개 좌표 정류소를 추가했습니다. 화면에는 `경기 <노선번호>`로 표시합니다.
- 실시간 위치 프록시가 일시적으로 연결을 끊으면 같은 조회를 한 번 재시도하고, 실패 원인을 사용자에게 표시합니다.
- 노선 선은 서울 TOPIS가 공개한 버스 운행 좌표를 사용합니다. 자동차 길찾기 선으로 대체하지 않습니다.
- 출발/도착 정류소 길찾기에 최적, 최소시간, 최단거리, 최소도보, 우회 경로를 넣었습니다.
- 같은 운행 구간의 여러 버스 번호는 한 카드로 묶고, 목적지를 지나친 뒤 되돌아오는 결과와 정류소 순환 결과를 제외합니다.
- 신호등 파서는 접근 방향, 서울식 1/10초 잔여시간, 만료/미래 시각을 검증합니다. 신호 API별 키 입력란을 설정 화면에 추가했습니다.
- 설정에서 실시간 신호등을 켜면 안내/시뮬레이션을 시작하지 않아도 현재 지도 중심 주변 교차로의 신호를 조회합니다. 안내 중에는 버스의 실제 진행 방향을 우선 사용합니다.
- 승인된 서울 T-DATA 교차로 Map·신호 잔여시간 키를 기본값으로 사용하고 최초 실행 시 신호등을 자동 활성화합니다. 설정에서 끄면 다음 실행에도 꺼진 상태를 유지합니다.
- 지도 버스 팝업의 `📍` 버튼을 켜면 선택한 차량의 실시간 좌표가 갱신될 때마다 지도가 차량을 따라갑니다. 다시 누르거나 다른 차량을 선택하면 추적이 해제됩니다.
- 서울 신호는 결합 API를 우선 사용하고, 응답이 비거나 불완전하면 신호 현시 API와 잔여시간 API를 합쳐 표시합니다. 교차로 Map을 포함한 네 서비스를 승인된 키로 자동 호출합니다.
- 서울 교차로 Map은 한 번에 조회해 브라우저에 30일간 보관합니다. 요청 제한(429)이 발생하면 저장된 목록을 계속 사용하고 30분 동안 같은 요청을 반복하지 않습니다. 실시간 신호 조회 주기는 10초입니다.
- 파일을 직접 여는 `file://` 실행에서는 브라우저가 차단하는 주소 기록 변경을 건너뛰어 `Unsafe attempt to load URL` 콘솔 오류가 발생하지 않습니다.
- 서울 노선을 열면 최근 7일 안의 `배차 차량운행별 이력`을 자동 조회해 자료가 있을 때 배차 차량 수, 운행 수, 첫 출발~마지막 도착 시간을 노선 헤더에 표시합니다. 빈 응답 또는 오류도 숨기지 않고 노선 상단에 상태를 표시합니다.
- 제공된 ITS 국가교통정보센터 CCTV 인증키를 기본값으로 넣고 `도로 CCTV 표시`를 최초 실행부터 켭니다. 현재 지도 영역의 고속도로·국도 HTTPS CCTV 핀이 표시되며, 핀을 누르면 영상과 새 창 링크가 열립니다.
- 노선 실시간 위치를 켜면 해당 노선의 현재 운행 대수를 노선 헤더에 표시하고, 674·6620·6637의 지정 예비차와 5620의 저상 아닌 차량은 무지개색 예비차 배지로 강조합니다. 배지를 누르면 해당 차량 위치를 엽니다.
- PWA 매니페스트와 오프라인 셸 캐시를 갱신했습니다.

데이터 및 제한
- TOPIS 노선 좌표 718개 중 716개를 2026-09-19에 받았습니다. 상암A21, 청와대A01은 공개 좌표가 없어 해당 노선은 실제 선을 표시할 수 없습니다.
- 일부 공개 노선의 가상/특수 정류소는 좌표 오차가 커서 해당 정류소를 포함한 세부 구간은 표시를 거절합니다.
- 길찾기의 시간·거리·도보 값은 정류소 데이터 기반 추정치입니다.
- `시간대별 돌발및우회 통계`는 월 1회 집계되는 구별 과거 통계이며 실시간 사고·우회 위치가 없으므로 현재 경로를 바꾸는 데이터로 사용하지 않습니다.
- 제공된 ITS CCTV 키는 현재 승인대기 상태이며 2026-09-24 직접 호출에서 HTTP 401을 반환했습니다. 승인 완료 전에는 앱에 `ITS CCTV 인증키 승인 대기 중입니다`가 표시되고, 승인된 뒤에는 설정 변경 없이 자동으로 작동합니다.
- 교차로 Map API가 429를 반환하고 저장된 교차로 목록도 없는 첫 실행에서는 신호 위치를 고를 수 없습니다. 제공기관의 호출 제한이 풀린 뒤 첫 교차로 목록 조회가 성공하면 이후에는 저장된 목록을 재사용합니다.
- 버스 도착정보의 Cloudflare Worker 연결 오류는 서울 신호 API와 별개의 프록시 오류입니다.
- 경기도 실시간 차량 위치는 제공 파일에 포함되어 있지 않습니다. 경기도 BMS 실시간 API 키와 호출 주소가 있어야 별도 연결할 수 있습니다.
- 경기도 BMS 경유정류소 파일의 `route_id`는 노선번호가 아니라 내부 노선 ID입니다. 승인된 노선 API에서 번호를 확인할 수 없는 항목은 화면에 `경기 노선 <ID>`로 표시해 ID를 번호로 오인하지 않게 했습니다.
- 실제 노선번호 메타가 없는 경기 내부 ID 항목은 이번 버전에서 검색·정류소 노선 목록에 표시하지 않습니다.
- 같은 노선번호가 여러 내부 노선에 매칭될 때도 이름으로 덮어쓰지 않고 각 `ROUTE_ID`를 별도 검색 결과로 유지합니다. 정류소에서 누른 노선도 해당 ID의 실제 경유정류소만 엽니다.
- 경기 BMS 노선은 정방향/반대방향 경유정류소를 따로 구성하고, 경기 좌표 파일에 없는 정류소도 서울 정류소 좌표와 node가 일치하면 보존합니다. 경기 700의 양방향 정류소 누락을 줄였습니다.
- 현재 포함된 경기도 선은 경유 정류소를 연결한 데이터입니다. 도로 형상 API의 별도 호출·키 설정이 필요하므로 TOPIS처럼 공식 링크 형상을 내장한 상태는 아닙니다.
